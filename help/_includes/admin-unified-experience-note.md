# 관리자 통합 경험 메모

>[!NOTE]
>
>Adobe Commerce as a Cloud Service의 Commerce 관리자는 공유된 Adobe 상단 탐색 및 업데이트된 Commerce 왼쪽 탐색과 함께 Adobe 통합 경험을 사용합니다. 자세한 내용은 [Adobe 통합 환경의 Commerce 관리자](/help/getting-started/admin-unified-experience.md)를 참조하십시오. 이 페이지의 화면 캡처는 클라우드 인프라 및 온프레미스 배포에서 Adobe Commerce에서 사용하는 클래식 Commerce 관리 인터페이스를 보여 줍니다.
