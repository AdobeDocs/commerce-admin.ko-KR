# 카탈로그 보기 참조 테이블

그리드는 공유 카탈로그가 [!DNL Adobe Commerce Optimizer]에 동기화되면 만들어진 각 카탈로그 보기에 대해 하나의 행을 나열합니다. 표는 키 할당 작업과 별도로 읽기 전용입니다. 커넥터가 Adobe Commerce에 구성된 공유 카탈로그를 동기화하면 카탈로그 보기가 자동으로 만들어지고 제거됩니다. 카탈로그를 제거하면 해당 카탈로그 보기 및 데이터를 삭제하기 전에 [유예 기간](/help/systems/catalog-view-sync-status.md#configure-the-deletion-grace-period)이 있습니다.

제한된 액세스 키를 할당하거나 할당을 취소하려면 [카탈로그 보기에 키 할당](/help/systems/restricted-access-keys.md#assign-keys-to-a-catalog-view)을 참조하십시오.

| 필드 | 설명 |
| --- | --- |
| [!UICONTROL ACO Catalog View ID] | [!DNL Adobe Commerce Optimizer]에 있는 해당 카탈로그 보기의 식별자입니다. 동기화 상태를 확인하려면 [카탈로그 보기 동기화 상태 요약](/help/systems/catalog-view-sync-status.md#catalog-view-sync-status-summary)을 참조하세요. |
| [!UICONTROL Store View] | 카탈로그 보기가 나타내는 스토어 보기입니다. [스토어 보기](/help/stores-purchase/store-views.md)를 참조하세요. |
| [!UICONTROL Access Keys] | 현재 카탈로그 보기에 할당된 제한된 액세스 키의 제목입니다. [제한된 액세스 키 관리](/help/systems/restricted-access-keys.md)를 참조하십시오. |
| [!UICONTROL Actions] | 카탈로그 보기에 대한 키를 할당하거나 할당 해제하려면 **[!UICONTROL Edit Restricted Access Keys]**&#x200B;을(를) 선택하십시오. [카탈로그 보기에 키 할당](/help/systems/restricted-access-keys.md#assign-keys-to-a-catalog-view)을 참조하세요. |
